# منهج التدبر في آيات القرآن الكريم

تطبيق ويب (PWA) لتدبّر القرآن الكريم يعرض التفسير **نصّاً كما هو من مصادره الموثّقة** دون أي تعديل، مع رابط المصدر بجوار كل نص.

🔗 الرابط: https://makkah2.github.io/tafsir/
مثال مباشر لآية: https://makkah2.github.io/tafsir/?s=1&a=5

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كاملاً (الواجهة + المنطق) |
| `data/fawaid.json` | «من فوائد الآيات» من المختصر، مستخرجة حرفياً لكل صفحة مصحف (604) |
| `scripts/extract-fawaid.js` | سكربت استخراج الفوائد وتحديثها |
| `manifest.json` | يجعل الموقع قابلاً للتثبيت كتطبيق على الجوال |
| `sw.js` | يحفظ الواجهة والفوائد للعمل بدون إنترنت |
| `icon.svg` | أيقونة التطبيق |
| `.nojekyll` | يمنع GitHub Pages من معالجة الملفات بـ Jekyll |

## مصادر المحتوى
**موسوعة القرآن الكريم QuranEnc.com** — جمعية خدمة المحتوى الإسلامي باللغات (تُجلب لحظياً من الـ API):
| المفتاح | الكتاب |
|---|---|
| `arabic_mokhtasar` | المختصر في تفسير القرآن الكريم — مركز تفسير للدراسات القرآنية |
| `arabic_moyassar` | التفسير الميسّر — مجمع الملك فهد لطباعة المصحف الشريف |
| `arabic_yaseer` | بيان معاني القرآن الكريم باللغة العربية |
| `arabic_nafahat` | النفحات المكية — محمد بن صالح الشاوي |
| `arabic_seraj` | معاني الكلمات (السراج في بيان غريب القرآن) |

رقم إصدار كل كتاب يُجلب من `https://quranenc.com/api/v1/translations/updates?key=<المفتاح>` ويُعرض بجوار النص.

**«من فوائد الآيات»** — من المختصر في التفسير. هذه الفوائد غير متاحة في واجهة QuranEnc البرمجية (حقل `footnotes` فارغ دائماً)، وتظهر فقط في صفحات الموقع لكل صفحة مصحف، وتلك الصفحات لا تسمح بالطلب المباشر من المتصفح (CORS). لذلك تُستخرج مرة واحدة حرفياً إلى `data/fawaid.json`، ويعرض التطبيق فوائد صفحة المصحف التي فيها الآية مع رابط صفحة الآية على QuranEnc.

**ابن كثير والسعدي** — نصوص quran.com عبر jsDelivr (`spa5k/tafsir_api`).
**نص المصحف للبحث** — alquran.cloud.

### شروط QuranEnc.com (ملتزم بها)
1. عدم التعديل أو الإضافة أو الحذف على المحتوى.
2. الإشارة بوضوح للناشر وللمصدر (QuranEnc.com).
3. ذكر رقم الإصدار عند إعادة النشر.

## ثوابت المشروع
- التفسير يُعرض نصاً كما هو من مصدره دون أي تعديل، مع رابط المصدر.
- لا يُنسب أي كلام لابن عثيمين أو ابن باز أو الفوزان؛ قسمهم **روابط بحث فقط** في مواقعهم الرسمية.
- قسم الذكاء الاصطناعي اختياري، مخفي افتراضياً، ولا يظهر إلا إذا أدخل المستخدم مفتاحه بنفسه، ومعه تنبيه «ليس تفسيراً معتمداً ولا فتوى».
- لا يوجد أي مفتاح API داخل الكود؛ المفتاح (إن أُدخل) يُحفظ في متصفح المستخدم فقط.

## تحديث «من فوائد الآيات»
يتطلب Node.js 18 أو أحدث:
```bash
node scripts/extract-fawaid.js
```
- يطلب صفحة واحدة لكل صفحة مصحف (604 طلباً)، طلباً واحداً في كل مرة، مع تأخير ثانية بين الطلبات، وباسم مستخدم (User-Agent) يعرّف بالمشروع.
- يلتزم بـ robots.txt في QuranEnc (يستخدم صفحات `/ar/browse/` ولا يستخدم `/ajax` المحجوب).
- يستغرق نحو 15–20 دقيقة، ثم يكتب `data/fawaid.json` بالشكل:
```json
{ "pages": { "1": ["فائدة", "..."] }, "ayahToPage": { "1:1": 1 }, "source": "...", "version": "1.0.0", "extracted": "YYYY-MM-DD" }
```
بعد التحديث ارفع رقم `CACHE` في `sw.js` ليحصل المستخدمون على النسخة الجديدة.

## التشغيل محلياً
```bash
npx serve .
```
أو `python -m http.server` ثم افتح `http://localhost:3000` (أو المنفذ الظاهر).

## إضافة مصدر تفسير جديد من QuranEnc
في `index.html` ابحث عن `CONFIG.sources` وأضف سطراً:
```js
{ key:'مفتاح_الترجمة', name:'الاسم', book:'الجهة', color:'#hex' },
```
ملاحظة: `https://quranenc.com/api/v1/translations/list/ar` تُرجع قائمة فارغة حالياً؛ تحقّق من المفتاح مباشرة عبر
`https://quranenc.com/api/v1/translation/aya/<المفتاح>/1/1`.

## ورد اليوم
- الصفحة الرئيسية تعرض **ورد اليوم**: نحو 5 آيات متتالية بتفسير المختصر (والميسّر عند الطلب) ثم «من فوائد الآيات».
- المصحف مقسّم إلى **1,252 ورداً** لا تعبر حدود السورة؛ إذا بقي في آخر السورة آية أو آيتان تُضمّان للورد السابق.
- اليوم يُحسب بتوقيت مكة، فالجميع يرى نفس الورد في نفس اليوم. اليوم الأول: `DAILY_START` في index.html (2026-11-06).
- رابط ورد محدد: `?day=3` — رابط آية محددة بكل التفاسير: `?s=2&a=255`.
